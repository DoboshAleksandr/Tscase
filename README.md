**Правила ведения тест-кейсов в формате markdown:**
- Тест-кейсы оформляются в отдельные файлы с уникальным именем, в котором отображена цель проверяемого сценария
- В конце имени файла указывается расширние .md
- Файлы хранятся в папках. Папка это отдельная страница приложения или отдельный блок, доска
- Тест-кейсы описаны в формате Шаг - Ожидаемый результат, чтобы их в дальнейшем можно было использовать при написание автотестов
